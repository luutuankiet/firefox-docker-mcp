# v0.12.1 - Text boxes for every script

**2026-11-21**

## TL;DR

Two fixes to `textBoxes`, found on the first live run against a multilingual page. Right-to-left
lines (Arabic, Hebrew) now come back as one box per line instead of one box per word, and a
line of text with no spaces that wraps (Chinese, Japanese) now gives a box for every line it
covers instead of only the first.

## Why

The line merge measured the gap from the end of the previous word to the start of the next,
left to right. In right-to-left text the next word in DOM order sits to the left, so the gap
was always negative and nothing merged. Separately, a "word" was found by splitting on
spaces, and only its first rectangle was kept; a CJK sentence is one such word, so when it
wrapped, every line after the first vanished.

## Highlights

| What | Detail |
|---|---|
| RTL lines | The gap is now measured on whichever side the next word sits. Text stays in reading order. |
| Wrapped words | A word that spans more than one rectangle is measured per character, then merged back into lines. |
| Tests | `test/text-boxes.mjs` gains a Hebrew line and a wrapped Chinese line, at dpr 1 and 2. |

## How it works

Both changes are in the in-page measuring function in `src/utils/text-boxes.ts`. Nothing
else changed; the output contract is the same.
